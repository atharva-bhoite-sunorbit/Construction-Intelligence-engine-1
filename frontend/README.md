# Construction Intelligence – Frontend

React 19 + TypeScript + Vite + Tailwind dashboard. See the root [README](../README.md) for full setup.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # typecheck + production build
npm run lint
```

The API base URL defaults to `http://localhost:8000`; override with `VITE_API_URL`.
