Project photos for the director's project cards.

Save a photo for each project here, named after the project:

  41-zoy-plus.webp     41 ZOY+, Hinjewadi (aerial render; the night and amenity renders are saved beside it)
  41-aventis.jpg       41 Aventis, Tathawade
  41-westworld.jpg     41 Westworld, Balewadi
  41-luxoverts.jpg     41 Luxoverts, Tathawade

A wide photo works best (about 1200 x 480 px, under 300 KB). Until a file is added the card shows a simple building
illustration instead. For a new project, set its cover_image_url to /projects/<file name>.

Any image format a browser can show works (jpg, png, webp); just make the project's cover_image_url match the file name.
